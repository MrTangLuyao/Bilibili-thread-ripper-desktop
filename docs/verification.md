## 0.9.1.1-d2 卸载按钮与安装行为

日期：2026-09-16。本次只调整维护操作和设置界面，没有修改共享下载核心。

- 浏览器回归检查红色“卸载 BTR”紧接在“检查 BTR 更新”右侧，确认和卸载期间禁用重复操作，取消后恢复按钮。
- 预加载入口与主进程单元测试覆盖真实点击限制、官方窗口限制、原生确认框默认取消、脚本完整性校验、更新与卸载互斥，以及失败后的重试。
- Windows PowerShell 5.1 在隔离的模拟客户端完成安装、重复安装、离线卸载、重启模拟官方 EXE 和还原后的哈希校验。
- 损坏原始备份时，在关闭客户端前拒绝卸载；不覆盖当前文件，不删除备份和账号数据。
- 安装不创建 BTR 快捷方式；升级清理匹配当前客户端的旧快捷方式。卸载清理对应快捷方式和安装记录，保留不相关的同名快捷方式和其他安装记录。

上述卸载流程在隔离测试环境验证，未用这一版按钮卸载用户正在使用的客户端。线上发布需要维护者 commit、push。
